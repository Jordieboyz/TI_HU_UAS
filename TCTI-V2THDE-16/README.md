# Theme Devices

For the Theme Assignment Devices (TCTI-V2THDE-16), based on a provided functional specification (Requirements Architecture), a set of UML models (Solution Architecture) is created for a real-time embedded system. This model is then implemented in C++ on an Arduino board with several hardware components connected to it. This implementation utilizes a provided real-time operating system (RTOS). Additionally, an investigation is conducted into the implementation of synchronization mechanisms in open-source real-time operating systems.
