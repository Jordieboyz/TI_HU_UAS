#  Object Oriented Programming in C++

A commonly used methodology for designing and implementing software is Object Orientation. In this approach, the functionality of the software is divided into reusable blocks, bringing more structure to the design and clearly indicating responsibilities in the code compared to procedure-oriented methods.

The aim of this course is to introduce the principles of object orientation and apply them to solve real-world technical problems. Parts of this course will be highly useful in preparation for the IPASS, the concluding project of the first year.
